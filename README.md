# محاسب محترف سوريا — ProAccountant Syria

برنامج محاسبة احترافي لأندرويد يعمل **بدون إنترنت**، مبني بـ Capacitor (HTML/CSS/JS).
**الإصدار الحالي:** 3.4.0 (versionCode 34) — المطوّر: باسل محمد الخابور — 0952575089

## أهم الميزات
- فواتير مبيعات ومشتريات (نقدي / آجل / تقسيط) بستة تصاميم احترافية، وطباعة A4 وحرارية 80/58mm، وPDF مطابق للمعاينة.
- مخزون وباركود (مسح بالكاميرا وطباعة ملصقات).
- عملاء وموردون، سندات قبض ودفع، مرتجعات، كشف حساب مفصل بفترة زمنية.
- لوحة أرباح وقائمة دخل وعشرة تقارير دقيقة.
- عملتان (دولار / ليرة سورية) بسعر صرف قابل للتعديل.
- قفل برمز PIN وبصمة الجوال.
- نسخ احتياطي مشفّر AES-256 على الجهاز و Google Drive، واستعادة مباشرة حسب التاريخ.
- واجهة عربية / إنجليزية، وضع ليلي / نهاري، متجاوبة مع كل مقاسات الشاشات.

## التشغيل والبناء
```bat
npm install              :: مرة واحدة
npm test                 :: الاختبارات الآلية
npx cap sync android     :: نسخ www إلى مشروع أندرويد
npx cap open android     :: فتح Android Studio ثم Build ← Build APK(s)
```
التفاصيل الكاملة (مفتاح التوقيع، بناء AAB، النشر على Google Play، ربط Google Drive) في [`README_RELEASE.md`](README_RELEASE.md).
